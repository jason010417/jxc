# 小團隊進銷存

觀心園愛心庇護工場的進銷存系統：採購、生產、外展借還、銷貨出貨、庫存總表、歷史查詢與 A4 單據列印。

- 網站：https://jason010417.github.io/jxc/
- 整個系統只有一個檔案 `index.html`，由 GitHub Pages 直接提供。
- 資料存在 Firebase Realtime Database（專案 `erp-app-90278`）的 `jxc/` 底下，與舊系統 erp-app 的 `erp/` 資料分開。

## 登入

用 Google 帳號登入。擁有者是 jason010417@gmail.com，其他人要由擁有者在「權限設定 → 可以登入的 Google 帳號」加入。名單存在資料庫的 `jxcMembers/`，Firebase 規則（見 `database.rules.json`）只讓名單裡的帳號讀寫 `jxc/`。

## 盤點重設

「盤點重設」頁可以指定盤點日、填入實際數量。存檔後，庫存從盤點日起算：盤點日當天及之後的單據才會加減，之前的單據留作歷史紀錄。

## 第一次使用

資料庫一開始是空的。用管理者身分按上方「還原備份」，選擇備份檔（.json）匯入，所有人就會看到同一份資料。

## 注意

- 這個專案是公開的，請不要把顧客、廠商等真實資料的備份檔放進來。
- 要在 Firebase 主控台開啟 Google 登入，並把 `jason010417.github.io` 加入授權網域。
- 定期按「備份資料」下載一份留存。
